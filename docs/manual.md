## 首页

登录后台后进入首页总览，可快速查看核心数据指标与常用功能入口。

### 快速进入

首页顶部提供 9 个快捷入口，点击可直接跳转对应功能模块：

| 入口 | 说明 |
|------|------|
| 会员列表 | 查看与管理所有会员信息 |
| 商品券 | 进入商品券管理页面 |
| 停车券 | 进入停车券管理页面 |
| 订单列表 | 查看所有交易订单 |
| 核销列表 | 查看券码核销记录 |
| 支付即积分 | 支付积分规则配置 |
| 停车支付订单 | 停车缴费订单查询 |
| BI 标准版 | 进入商业数据分析平台 |
| 系统配置说明 | 查看系统配置相关文档 |

### 数据简报

展示当月核心经营数据（实时更新）：

| 指标 | 说明 |
|------|------|
| 本月新增会员 | 当月新注册会员数量 |
| 总会员数 | 累计注册会员总数 |
| 总成交金额（本月） | 当月全部交易金额合计 |
| 总交易笔数（本月） | 当月交易订单总笔数 |

### 系统公告

展示平台重要通知与更新公告，点击「查看更多」可查看历史公告列表。

### 数据图表

首页下方提供多维数据可视化看板：

- **商场每月销售统计**：月度销售额趋势柱状图
- **商场每月业态统计**：各业态销售占比堆叠图
- **业态消费统计（当月）**：当月各业态消费占比玫瑰图
- **会员数据板块**：会员分层漏斗图（忠诚会员 / 高粘性会员 / 摇摆会员 / 沉睡会员），点击可跳转到 BI 标准版查看 RFM 详细数据
- **会员消费排名（当月）**：当月会员消费金额 TOP 排行
- **门店销售排行（当月）**：当月门店销售额 TOP 排行

## 小程序管理

### 小程序列表

#### 新增小程序

1. 进入「小程序管理 → 小程序列表」，点击「添加小程序」
2. 在弹窗中填写以下信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 小程序名称 | ✓ | 小程序的显示名称 |
| 归属商户 | ✓ | 选择该小程序归属的商户 |
| 小程序 appid | ✓ | 微信小程序的 appid |
| 小程序 secret | ✓ | 微信小程序的 secret |
| 微信商户号 | — | 微信支付商户号 |
| 每日停车减免 | — | 每日停车减免额度配置 |
| 停车收费商户号 | — | 停车收费对应的商户号 |
| 导航栏颜色 | — | 小程序顶部导航栏颜色 |
| 注册赠送积分 | — | 新会员注册时赠送的积分数量 |
| 微信会员卡 id | — | 微信会员卡模板 id |
| 支付宝 appid | — | 支付宝小程序 appid |
| 支付宝会员卡模板 id | — | 支付宝会员卡模板 id |
| 支付宝授权 Token | — | 支付宝授权令牌 |
| 支付宝 aes 秘钥 | — | 支付宝加密秘钥 |
| 美团智慧商圈 ID | — | 美团平台商圈 ID |
| 经纬度 | — | 商圈地理位置，点击地图按钮选择 |
| 首页底部广告图 | — | 上传图片，≤2MB，png/jpg/jpeg，建议尺寸 212×750 |
| 小程序启动图片 | — | 上传图片，≤2MB，png/jpg/jpeg，建议尺寸 1080×1920 |

3. 确认信息无误后，点击「确定」保存

#### 列表查询与管理

1. 进入「小程序管理 → 小程序列表」，展示所有已创建的小程序
2. **搜索筛选**：支持按「小程序名称」和「小程序 appid」模糊搜索，点击「重置」清空条件
3. **批量操作**：勾选左侧复选框，可进行批量修改、删除、更新缓存

#### 单行操作说明

在列表右侧「操作」列，可对单条小程序执行以下操作：

| 操作 | 说明 |
|------|------|
| 修改 | 打开编辑弹窗，修改小程序配置信息 |
| 删除 | 删除该小程序（谨慎操作） |
| 上传支付宝版本 | 上传支付宝小程序代码包 |
| 提审支付宝版本 | 提交支付宝小程序审核 |
| 积分清零 | 清空该小程序下所有会员积分（谨慎操作） |

列表支持分页展示，默认每页 10 条，可切换分页查看。

| 显示类型 | ✓ | 选择活动对应的板块类型（见下表） |
| 状态 | ✓ | 启用 / 禁用，默认禁用 |
| 商品显示数量 | ✓ | 该板块展示的商品数量 |
| 显示顺序 | ✓ | 数字越小越靠前 |
| 活动开始日期 | — | 活动生效日期 |

| 活动结束日期 | — | 活动失效日期 |

| 可用星期 | — | 勾选该活动在星期几展示 |

| 悦品推荐 | 首页推荐商品板块 | — |

- 支持按条件筛选和搜索
- 可对活动进行编辑、删除、启用/禁用操作

### 支付积分订单

支付积分订单记录会员在线下门店通过微信支付消费后，系统根据「支付即积分」规则自动返还积分的流水。该功能需先完成微信支付商户号打通及积分规则配置。

| 支付时间 | 日期范围，按交易完成时间过滤 |

> **操作**：点击「搜索」执行查询；点击「重置」清空条件；点击「导出」可导出对账及积分发放报表。

| 电话 | 会员绑定的手机号 |

#### 积分计算规则

- 不同业态/门店可配置不同的积分返还比例（如 1 元 = 1 积分、1 元 = 0.5 积分等）。
- 积分通常在支付成功后实时到账，延迟不超过 5 分钟。
- 若用户发起退款，系统会自动扣回对应积分，退款标记将同步更新。

#### 注意事项

- 该列表仅展示通过「支付即积分」功能产生的积分流水，不包含签到、活动奖励等其他积分来源。
- 如需查看会员全部积分变动，请前往「会员中心 → 会员列表 → 积分明细」。
- 交易订单号可与微信支付商户后台流水进行交叉对账。

### 异常积分管理

异常积分管理用于识别并处理会员在「支付即积分」场景下的异常消费行为，防止刷单套利，保障积分体系健康。

#### 页面路径
首页 / 订单中心 / 异常积分管理

#### 异常积分规则

> **规则说明**：以自然月为统计单位，同一会员在同一柜台/门店 **30 天内消费 > 7 次** 即触发积分异常。该阈值兼顾正常高频消费与恶意刷单场景，可根据业务需求联系技术调整。

#### 检索条件

| 字段 | 说明 |
|------|------|
| 日期 | 月份选择器（如 `2026-01`），按自然月统计异常数据 |

> **操作**：选择月份后点击「搜索」；点击「重置」恢复默认；点击「导出」可导出当月异常会员清单。

#### 列表字段

| 字段 | 说明 |
|------|------|
| 昵称 | 会员在小程序中的昵称 |
| 手机号 | 会员绑定的手机号 |
| 消费次数 | 该会员在统计周期内的消费笔数 |
| 积分数 | 该会员在统计周期内获得的积分总额 |
| 操作 | **点击查看**：查看该会员的详细消费流水；**积分处理**：手动扣减或补发积分 |

#### 积分处理

点击「积分处理」后弹出处理窗口：

| 字段 | 说明 |
|------|------|
| 剩余积分 | 该会员当前账户剩余积分（只读） |
| 积分处理 | 输入调整数值：正数为补发积分，负数为扣减积分（如 `-15`） |
| 积分描述 | 填写调整原因，便于后续审计追溯 |
| 所属商户 | 下拉选择积分变动归属的门店/商户（必填） |

> **操作**：填写完成后点击「确定」提交；点击「取消」关闭窗口。积分调整将实时同步至会员账户并在「积分明细」中留痕。

#### 注意事项

- 异常积分管理仅针对「支付即积分」产生的积分，不包含签到、活动奖励等其他来源。
- 积分扣减操作不可逆，请核实消费流水后再处理。
- 建议定期（如每月初）导出上月异常数据，复盘并优化积分规则或阈值。

## 智慧营销

### 精准发券

精准发券支持向指定会员群体定向发放优惠券，适用于节日营销、会员唤醒、补偿安抚等场景。支持直接发券与批量导入发券两种模式。

#### 页面路径
首页 / 智慧营销 / 精准发券

#### 直接发券

在页面上方输入发券信息，查询目标人群后一键发放：

| 字段 | 说明 |
|------|------|
| 备注 | 填写本次发券活动的备注说明，便于后续追溯 |
| 券号 | 输入要发放的商品/优惠券编号 |
| 发券数量 | 输入每位会员发放的张数 |

> **操作**：填写券号和发券数量后，点击「查询人数」可预览符合条件的会员数量；确认无误后点击「一键发券」执行发放。

#### 批量导入发券

针对大批量、特定名单的定向发券需求，可通过 Excel 模板导入会员列表后批量发放：

1. 点击「导入发券」按钮，弹出上传窗口。
2. 点击「下载模板」获取标准 Excel 模板，按模板格式填写会员信息（通常包含手机号、券号、数量等字段）。
3. 将填好的文件拖拽至上传区域，或点击上传选择文件（仅支持 `xls`、`xlsx` 格式）。
4. 点击「确定」完成导入，系统将按表格内容逐条发券。

#### 列表字段

| 字段 | 说明 |
|------|------|
| 微信昵称 | 会员在小程序中的昵称 |
| 手机号 | 会员绑定的手机号 |
| 积分 | 会员当前积分余额 |
| 会员标签 | 该会员被打上的标签（如「高价值用户」「沉睡用户」） |
| 备注 | 发券时填写的备注信息 |

#### 注意事项

- 精准发券仅支持发放普通优惠券，不支持停车券。
- 批量导入前请务必下载最新模板，避免字段格式不符导致导入失败。
- 发券操作通常不可逆，请核对券号及数量后再确认发放。
- 发券后会员将实时在小程序「券包」中收到该优惠券。

## BI商业分析

### 会员数据分析（标准版）

会员数据分析提供多维度的会员画像与消费行为看板，帮助运营团队洞察会员价值、识别沉睡用户、制定差异化营销策略。

#### 页面路径
首页 / BI商业分析 / 会员数据分析（标准版）

#### 看板模块

**1. 会员消费（积分）数据分层**

以漏斗图展示会员的消费活跃度分层，支持按「总会员数」等维度筛选：

| 层级 | 说明 |
|------|------|
| 总会员数 | 系统注册会员总量 |
| 近一个月未消费 | 最近 30 天内无消费记录的会员数 |
| 近三个月未消费 | 最近 90 天内无消费记录的会员数 |
| 近半年未消费 | 最近 180 天内无消费记录的会员数 |

> 通过该漏斗可快速识别流失风险：漏斗越宽，说明短期沉睡会员占比越大，需及时触发唤醒营销。

**2. 会员消费频次分析**

以金字塔图将会员按年消费频次划分为四类，点击「下载」可导出对应人群列表：

| 会员类型 | 定义 | 用途 |
|----------|------|------|
| 忠诚会员 | 一年消费 **30 ~ 100** 次 | 核心高价值用户，适合专属权益、裂变激励 |
| 高粘性会员 | 一年消费 **15 ~ 29** 次 | 活跃主力，适合推新品、组合套餐 |
| 摇摆会员 | 消费频次介于沉睡与活跃之间 | 易流失群体，适合限时优惠券召回 |
| 沉睡会员 | 长期无消费 | 需强利益点（大额券、积分翻倍）唤醒 |

**3. 会员授权类型分布**

环形图展示会员授权状态：

| 指标 | 说明 |
|------|------|

> 点击「下载未快速授权用户」可导出尚未开通支付即积分的会员名单，便于定向引导授权。

展示已绑定车牌的会员占比（如 **71.0%**），反映停车场景的用户渗透率。

#### 使用建议

- **定期复盘**：建议每月初查看「会员消费频次分析」，及时调整当月会员运营重点。
- **分层运营**：将「下载」的人群包导入「智慧营销 → 精准发券」，实现千人千面的券投放。
- **流失预警**：关注「近一个月未消费」人数环比变化，若连续两月上升，需检查商品券吸引力或推送触达率。

## 门店核销

### 核销操作流程

门店核销员可通过小程序端完成优惠券的扫码核销，无需登录电脑后台。

#### 操作步骤

**一、进入小程序个人中心**

会员或核销员打开小程序，点击底部「我的」进入个人中心页面。

**二、点击商家管理**

在个人中心菜单列表中，找到并点击「**商家管理**」入口。

**三、门店核销员登录**

进入「商户登陆」页面，输入门店后台分配的**账号**和**密码**，点击「登陆」。

> **说明**：该账号由项目管理员在「商户管理 → 账号管理」中创建，一门店可配置多个核销账号。

**四、扫码核销**

登录成功后进入「商户管理」页面：

1. 点击「**+扫码核销优惠券**」按钮，唤起摄像头扫描会员出示的券码。
2. 扫码成功后系统自动核销，会员小程序中的该券状态同步变为「已使用」。

**五、查看记录与统计**

页面下方提供三个 Tab 切换：

| Tab | 说明 |
|-----|------|
| 优惠券核销记录 | 查看本门店所有已核销的优惠券流水 |
| 交易记录 | 查看与本门店相关的交易订单 |
| 核销统计 | 按时间段统计核销笔数、金额等汇总数据 |

#### 注意事项

- 核销操作即时生效，请确认券码无误后再扫码。
- 若账号无法登录，请联系项目管理员检查账号状态及密码是否正确。
- 纯停车券的核销请使用对应停车系统的管理后台，不在此小程序核销范围内。

## 圈店流程

圈店流程用于将线下门店纳入微信/支付宝商圈体系，打通支付数据回传通道，实现会员消费自动积分。整个流程由技术服务商协助完成，商户仅需配合提供必要资料。

### 申请官方账号及商圈能力权限

以商管主体申请微信支付官方账号和支付宝企业账号（可由技术服务商代申请），后续由技术服务公司代为申请商圈官方能力接口。

| 平台 | 说明 |
|------|------|
| 微信侧 | 申请微信支付商户号及商圈能力接口权限 |
| 支付宝侧 | 申请支付宝企业账号及商圈相关能力接口 |

### 门店圈入方式

门店需完成以下三种方式中的至少一种，方可被纳入商圈支付数据抓取范围：

1. **现场支付抓取**
   - **微信**：需在门店现场完成一笔真实支付，以验证支付通道归属。
   - **支付宝**：无需现场支付，可直接通过后台配置完成圈入。
2. **录入已有的订单号**
   - 提供该门店近期已完成的支付订单号，由技术方在后台录入匹配。
3. **门店支付通道的商户号**
   - 直接提供门店当前使用的微信支付商户号或支付宝商户号，进行绑定。

### 录入门店信息及门店编号

在系统后台录入门店基础信息，确保与微信/支付宝商圈平台的门店数据一一对应：

| 字段 | 说明 |
|------|------|
| 门店名称 | 与营业执照及支付商户号一致的门店名称 |
| 所属业态 | 选择该门店对应的业态分类 |
| 门店编号 | 由技术服务商在系统后台自动生成，再录入微信/支付宝商圈平台进行编号匹配 |

> **注意**：门店编号必须保持两端（本系统后台与微信/支付宝商圈平台）一致，否则支付数据无法正确回传。

### 现场测试

录入相关门店信息后，进入现场测试环节：

1. 测试人员注册成为小程序会员。
2. 在门店现场进行真实消费支付。
3. 验证支付数据是否成功回传至系统，会员是否自动获得对应积分。
4. 若测试失败，检查门店编号、商户号、支付通道配置是否一致。

### 商家须知（供购物中心门店宣导使用）

为保障会员积分体系正常运转，请各合作商家配合以下事项：

1. **宣导入会流程**：配合商场管理方，积极宣导本项目的会员入会流程，并在店内适当位置张贴相关物料。
2. **收单渠道变更报备**：商家在经营过程中，如因自身发展需要更换移动支付收单渠道（如更换支付服务商、变更商户号等），**须提前告知商场管理方**，由技术公司安排人员重新录入门店收单信息。
3. **消费积分异常反馈**：如消费者正常消费后无法自动积分，请积极引导消费者联系管理方，由相关技术团队验证后及时处理，保障消费者合法会员权益。
