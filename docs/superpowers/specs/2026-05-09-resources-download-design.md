# 资料与附件页面设计

## 目标

在现有 VitePress 文档站中新增“资料与附件”页面，方便客户下载上线前需要准备的纸质资料、模板文件，或打开微信官方操作说明链接。

## 范围

本次只新增文档站页面，不建设登录后台、数据库或线上上传功能。

## 页面入口

在 `docs/.vitepress/config.mjs` 的 `Reference` 分组下新增菜单项：

- 常见问题
- 更新日志
- 资料与附件

菜单链接指向 `/resources`。

## 页面文件

新增 `docs/resources.md`。

页面包含两个分类：

1. 微信官方资料及操作说明
2. 本系统的资料

## 资料条目样式

每个资料条目使用说明版内容：

- 资料名称
- 简短说明
- 文件类型或来源
- 操作按钮：下载附件或打开链接

## 第一版资料内容

### 微信官方资料及操作说明

- 微信支付商户平台操作指引
- 微信小程序认证与备案说明
- 微信支付产品能力说明
- 商户号配置说明

这些条目优先支持外部链接，真实链接未提供前使用占位提示，避免伪造官方 URL。

### 本系统的资料

- 商户入驻资料清单
- 停车系统对接资料清单
- 小程序页面装修资料说明
- 系统上线前检查清单
- 会员隐私协议模板

这些条目优先支持本地附件下载。真实附件未提供前，页面显示“待上传附件”，避免生成无效下载链接。

## 附件目录

新增目录：

```text
docs/public/downloads/
```

后续附件放入该目录。VitePress 构建后，下载路径可使用：

```text
/downloads/文件名
```

## 验收标准

- 文档站左侧 `Reference` 下出现“资料与附件”。
- 点击后进入 `资料与附件` 页面。
- 页面按两个分类展示资料列表。
- 每个资料都有名称、说明、来源或文件类型、操作状态。
- 没有真实附件或真实官方链接时，不生成虚假下载地址或官方链接。
