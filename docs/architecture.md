# 系统架构

```
┌─────────────────────────────────────────┐
│          智慧商圈数智中台                  │
├─────────────────────────────────────────┤
│  会员系统  │  营销中心  │  积分商城  │  数据看板  │
├─────────────────────────────────────────┤
│  微信支付  │  支付宝   │  美团     │  抖音     │
├─────────────────────────────────────────┤
│           商圈独立会员数据库               │
└─────────────────────────────────────────┘
```

## 分层说明

### 接入层
- 微信支付、支付宝、美团、抖音等多渠道支付数据回传
- 标准 REST API 接口
- Webhook 事件推送

### 数据中台
- 商圈独立会员数据库
- 积分、券、等级、标签统一管理
- 数据加密传输与存储

### 应用层
- **会员系统**：注册、积分、等级、画像
- **营销中心**：券发放、活动配置、自动营销
- **积分商城**：商品管理、兑换、停车券
- **数据看板**：消费分析、会员分析、效果复盘
