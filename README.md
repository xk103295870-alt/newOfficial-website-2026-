# WNTC 官网

纯静态网站，无构建和安装步骤。直接用浏览器打开本目录的 `index.html`，或在此目录启动本地静态服务器。字体来自 Google Fonts；网络不可用时回退到系统无衬线字体，正文不依赖 JavaScript 才能显示。

## 页面与维护

- `index.html`：导航、固定英文首屏、工作室简介、概念作品、服务、理念、创意实验室、手记和联系。
- `styles.css`：颜色、字体和布局变量集中在 `:root`。统一页面边距、响应式栅格，1000px 以下提供手机导航，640px 以下使用单列内容。
- `main.js`：语言、下拉菜单键盘操作、手机菜单、项目弹窗、导航当前位置与年份。
- `assets/logo-nav.png`：导航优化版 Logo；原来的 `assets/logo.png` 保留作为素材。

## 中英文

默认中文，选择保存在 `localStorage` 的 `wntc-lang` 中；存储不可用时仍可切换。元素的中文内容直接写在 HTML，英文使用 `data-en`；无障碍标签的译文使用 `data-en-label`。语言菜单显示中文和 English，并提供当前选择标记、方向键操作、Esc 关闭和焦点返回。标题、描述和文档语言同步切换。

大标题 **Design & Technology** 以及概念作品画面中的英文固定显示，其他界面文案随语言选择变化。

## 智慧商圈操作说明

文档站已从 https://github.com/xk103295870-alt/newOfficial-website 迁入本项目的 docs 目录，保留原 VitePress 主题、深浅色切换、目录、搜索和中文内容。详情页三个操作说明入口均打开 docs/manual.html，不再跳转旧站。文档导航“首页”返回本项目首页。

### 本地预览

请从本项目根目录启动 HTTP 服务器（不要直接双击文档 HTML）：

```sh
python3 -m http.server 8080
```

访问 http://localhost:8080/ 和 http://localhost:8080/docs/manual.html 。文档正文、主题与搜索资源在本地；Google 字体及第三方参考链接仍需要网络，字体不可用时回退系统字体。

### 修改与构建文档

编辑 docs/*.md，主题文件在 docs/.vitepress/theme 中。安装依赖后构建并复制输出：

```sh
npm ci
npm run docs:build
cp -R .docs-build/. docs/
```

构建输出到 .docs-build，避免覆盖 Markdown 源文件。docs/superpowers 为原仓库的内部设计资料，排除在站点构建之外。部署时将官网静态文件和 docs/ 的 HTML、assets、logo.svg、hashmap.json 等构建资源一起发布到站点根目录；无需部署 node_modules、.docs-build 或文档源文件。文档 base 为 /docs/，若发布到子路径需调整 base 并重新构建。

## Work 封面交互
work-background.js 根据用户提供的视频，实现作用于封面 SourceGraphic 的液体位移。鼠标轨迹驱动 RG 位移图与 SVG feDisplacementMap，图片、图形及封面内文字一起局部变形；不叠加颜色，卡片外标题不受影响。停止移动后约 1.35 秒恢复；触摸、减少动态、高对比、离屏及隐藏时停用。前期水彩叠层和像素遮罩均不再加载。
